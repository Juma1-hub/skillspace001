SKILLSPACE — Referral, Navigation & Visual Polish Update

Deploy-ready static frontend files are in this folder. See the root README.txt for feature details and the prototype/backend limitations. The current version includes referral codes and 25% demo commissions after manual verification, dashboard referral metrics, admin referral-code assignment, light/dark mode, persistent quick navigation, back buttons, clickable membership cards, Academy course previews for non-Premium plans, randomized listing order, and custom SVG branding.

Important: this is still a browser-local frontend demo. Referral records and payment status do not synchronize across users/devices, and the interface does not initiate or verify real M-Pesa transactions. Connect a secure backend before production use.
