SKILLSPACE Starter Prototype
============================

Files
-----
- index.html: responsive, interactive front-end prototype.

How to preview
--------------
1. Extract the ZIP file.
2. Open index.html in a modern web browser.
3. Try "Get started" to open a demo member workspace.
4. Explore the workspace sidebar and sample interactions.

Important
---------
This is a front-end prototype, not a production platform. Login details are not sent to a server; the demo stores a name/email in browser localStorage only. Job listings, earnings, affiliate links, withdrawals, payments, courses, referrals, and marketplace content are illustrative. No real money movement or real job matching is connected.

Production build still required
-------------------------------
- Backend/API and production database
- Secure authentication, email verification, password reset, and role permissions
- Admin and reviewer workflows
- Real job posting, applications, work submissions, review, and dispute handling
- Payment provider setup and secure transaction ledger (including M-Pesa if approved)
- Membership plans and entitlement checks
- Affiliate/referral attribution, fraud controls, and commission rules
- Course authoring and progress tracking
- Marketplace listings, orders, seller controls, and refunds
- Optional games/rewards module with clear rules
- Privacy policy, terms, community guidelines, support, audit logs, backups, monitoring, and security testing
