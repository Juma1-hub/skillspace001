SKILLSPACE — Complete Frontend Prototype
========================================

Files:
- index.html: responsive static frontend.
- vercel.json: Vercel static deployment configuration.
- README.txt: these instructions.

UPLOAD TO GITHUB:
1. Extract this ZIP.
2. Open your GitHub repository.
3. Upload the CONTENTS of this folder to the repository ROOT.
4. Make sure index.html and vercel.json are visible at the top level beside README.txt.
5. Commit the files.
6. Check Vercel Deployments for the new deployment.

VERCEL:
The project is plain HTML, not a Next.js/React app. Framework Preset should be Other.
If Vercel's settings allow overrides, disable Build Command and Install Command.
Use the repository root as the Root Directory. The included vercel.json provides static routing.

IMPORTANT LIMITATIONS:
This is a complete FRONTEND PROTOTYPE, not a complete production platform/backend.
The demo signup/profile uses browser localStorage only and is not secure authentication.
Job listings, budgets, courses, referrals, earnings, memberships and withdrawals are illustrative.
No real applications are submitted; no commissions are calculated; no money is held or transferred.
M-Pesa, bank and international payments are NOT connected.
Do not enter real passwords or sensitive information.

Before production launch, SKILLSPACE still needs a secure backend, database, server-side authentication,
admin tools, real job/course workflows, final membership rules, audit logs, legal/privacy review,
security testing and approved payment integrations.
